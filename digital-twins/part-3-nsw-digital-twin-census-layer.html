City digital twin · Part 3 · The side quest

Exploring the official NSW Digital Twin portal

I'd been living inside city simulators for weeks: SUMO, MATSim, and the twin stacks underneath them. On census night I happened to have the official New South Wales digital twin open, realised I could layer my own data onto it, and couldn't resist a small experiment: put the census itself on the map, one parcel at a time.

August 2026 · ~11 min read · Part 3 of a series

§1Official digital twins

The two posts before this one argued about city twins from the outside. Part 1 wrote down the mental model and recorded the corrections; Part 2 checked that argument against a decade of programs. This post is a side quest: I went and stood inside one.

I'd been working my way through the digital-city-twin space: reading up on the stacks people build them on, and happily running my own simulations. Road traffic in SUMO (Simulation of Urban MObility), agent-based travel demand in MATSim (Multi-Agent Transport Simulation), that kind of thing. Sooner or later that curiosity turns to the question: what do the real twins look like, the official ones governments actually run?

In New South Wales (NSW) the answer is the NSW Spatial Digital Twin, a government-run 2D/3D/4D model of the state built by the Department of Customer Service (DCS) Spatial Services with Data61, the digital research arm of the Commonwealth Scientific and Industrial Research Organisation (CSIRO). Its public front door is the Spatial Digital Twin Explorer (SDT Explorer), the viewer that in May 2025 replaced the long-serving Spatial Information eXchange (SIX) Maps, laying authoritative spatial data over a precise basemap of every street, parcel and building. Esri, the company whose mapping platform runs it, calls it "one of the largest spatial digital twins in the world," now spanning more than nineteen council areas.

It isn't the only one. Most Australian states have stood up a twin, and they interlink into a loose national ecosystem.

§2The stack

My own experiments had been on the simulation side of the twin world: engines that move agents and vehicles around a network. The official twin is the other half, the authoritative, continuously updated model of the physical city those simulations want to run against.

  • SUMO · traffic microsimulation
  • MATSim · agent-based transport
  • TerriaJS + Cesium · open-source twin viewers
  • Esri ArcGIS · the NSW twin's platform

SDT Explorer is a browser app over an ArcGIS Enterprise back end. Every dataset is a Representational State Transfer (REST) service you can query directly, and that was the moment the side quest suggested itself: if the layers are open services and there's an "Add your own data" button, then anything I could shape into a spatial file could sit on the same map.

§3Layers, formats, and the fabric of the cadastre

The base data is organised into a handful of authoritative themes, each a live service: Land Parcel & Property (lots), Geocoded Addressing (points), Administrative Boundaries, Imagery, Elevation & Depth, Transport and Water.

To add your own, the uploader accepts a short menu of formats: zipped shapefile, CSV, KMZ, geotagged JPEG, GPX, and a web service URL. The zipped shapefile is the one that carries polygons and a full attribute table, so it's what a lot-level census layer has to be.

§4A census-night coincidence

The timing was pure accident. The evening I was poking around the official twins happened to be census night, 11 August 2026. I'd filled in the form for my current location a few hours earlier. So when it clicked that the twin would take my own layers, the obvious playful question was: could I put the census itself on this map? It seemed like a fun thing to try on the one night of the year everybody is being counted.

Fresh census data takes many months to publish, and NSW won't see 2026 figures until well into 2027, so I reached back to the 2021 census night instead, the last time everyone was counted (10 August 2021). And there was a real puzzle to make it interesting. The Australian Bureau of Statistics (ABS) never publishes "where people actually were" below the Statistical Area Level 1 (SA1), a statistical area of a few hundred people. Nothing exists at the parcel level. Getting to a per-lot layer meant borrowing detail from the cadastre itself, in three moves.

A. Get the census-night data

From the ABS 2021 Place of Enumeration Profile (PEP) DataPack (table P01, Tot_P_P) for every NSW SA1, plus the Mesh Block counts spreadsheet for residents and dwellings. Both pulled straight from abs.gov.au.

B. Scope it to Forest Lodge

Query the ABS boundary service for the Forest Lodge suburb polygon, take the Mesh Blocks whose centre falls inside it, and keep only their 12 SA1s, clipping a state-wide file down to one square-kilometre neighbourhood.

C. Transform and disaggregate to lots

Split each SA1's count across its Mesh Blocks (by usual residents), then across the lots inside each Mesh Block, weighted by the number of geocoded address points on the lot, so a 25-unit apartment block draws 25× a single house. Write the result as a zipped shapefile.

Twenty-one attribute fields ride along on every lot: cadastre IDs, the Mesh Block and SA1 it sits in, the published counts it was derived from, the address-point weight, and the estimate itself (PERSONS / PERSONS_R). The file is 378 kilobytes and uploads to SDT Explorer in seconds. The orange colour coding on the map is applied by the same script.

§6The build script, in full

Everything below actually ran, in two browser consoles. Part A on abs.gov.au, because its DataPack downloads are only fetchable from that origin, and Parts B and C on the SDT Explorer tab. No desktop mapping software, no build step, no libraries: the shapefile and ZIP writers are hand-rolled so the whole pipeline fits in a console paste.

Overview and data sources

What the pipeline is, where every dataset comes from, and how to run it.

/*
 * build_census_lot_layer.js
 * -------------------------------------------------------------------------
 * Builds a zipped shapefile of NSW cadastral lots carrying an estimate of the
 * number of people counted on each lot on 2021 Census night (10 Aug 2021),
 * ready to upload to the NSW Spatial Digital Twin (SDT Explorer, "Add your own").
 *
 * Why it runs in the browser: the ABS DataPack zip is only fetchable
 * same-origin from an abs.gov.au tab, and the NSW / ABS map services are
 * CORS-open, so two browser tabs do all the work with no server-side tooling.
 *
 * HOW TO RUN
 *   PART A  - open https://www.abs.gov.au/census/find-census-data/datapacks
 *             open DevTools console, paste PART A, run:  await partA(SA1_CODES)
 *             (SA1 codes come from PART B step 1; run B1 first, then A, then B2)
 *   PART B  - open https://portal.spatial.nsw.gov.au/explorer/index.html
 *             open DevTools console, paste PART B, run:
 *                const ctx = await partB1("Forest Lodge");   // -> prints SA1 codes
 *                ... run partA in the ABS tab with those codes, copy its output ...
 *                await partB2(ctx, ABS_OUTPUT_STRING);        // builds + downloads zip
 *
 * DATA SOURCES
 *   ABS 2021 Census Place of Enumeration Profile (PEP) DataPack, SA1, NSW
 *     https://www.abs.gov.au/census/find-census-data/datapacks/download/2021_PEP_SA1_for_NSW_short-header.zip
 *     table P01, column Tot_P_P = persons counted where they were on Census night
 *   ABS 2021 Mesh Block counts (usual residents + dwellings per Mesh Block)
 *     https://www.abs.gov.au/census/guide-census-data/mesh-block-counts/2021/Mesh%20Block%20Counts%2C%202021.xlsx
 *   ABS ASGS 2021 Mesh Block and Suburb (SAL) boundaries
 *     https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/MB/MapServer/0
 *     https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/SAL/MapServer/0
 *   NSW Land Parcel & Property Theme - Lot polygons (DCS Spatial Services)
 *     https://portal.spatial.nsw.gov.au/server/rest/services/NSW_Land_Parcel_Property_Theme/FeatureServer/8
 *   NSW Geocoded Addressing Theme - Address points
 *     https://portal.spatial.nsw.gov.au/server/rest/services/NSW_Geocoded_Addressing_Theme/FeatureServer/1
 *
 * METHOD (two-stage dasymetric disaggregation)
 *   1. SA1 census-night persons  -> Mesh Blocks in that SA1, weighted by the
 *      Mesh Block's usual-resident count (fallback: dwellings, then equal).
 *   2. Mesh Block persons        -> lots whose centroid lies in the Mesh Block,
 *      weighted by geocoded address points on the lot. If a lot has unit
 *      addresses ("3/23 Ross St") only the unit points are counted, so the
 *      building's base address isn't double counted. Lots with no address
 *      points get 0 (fallback to lot area if a whole Mesh Block has none).
 *   Lot-level values are therefore modelled estimates that sum back exactly to
 *   the published SA1 totals; the ABS applies small random perturbation to all
 *   published cells.
 */

Step A - Get the census-night data

Downloads the ABS Place of Enumeration DataPack and the Mesh Block counts, and reads them straight out of the .zip and .xlsx in the browser.

// ============================ PART A (abs.gov.au tab) ==========================
const Z = {};
Z.readZipDir = (buf) => {
  const dv = new DataView(buf), u8 = new Uint8Array(buf), td = new TextDecoder();
  let eocd = -1;
  for (let i = buf.byteLength - 22; i >= Math.max(0, buf.byteLength - 70000); i--) if (dv.getUint32(i, true) === 0x06054b50) { eocd = i; break; }
  if (eocd < 0) throw new Error("no EOCD");
  const n = dv.getUint16(eocd + 10, true), cdOff = dv.getUint32(eocd + 16, true);
  const entries = []; let p = cdOff;
  for (let i = 0; i < n; i++) {
    const method = dv.getUint16(p + 10, true), csize = dv.getUint32(p + 20, true), usize = dv.getUint32(p + 24, true);
    const fnl = dv.getUint16(p + 28, true), exl = dv.getUint16(p + 30, true), cml = dv.getUint16(p + 32, true), lho = dv.getUint32(p + 42, true);
    entries.push({ name: td.decode(u8.subarray(p + 46, p + 46 + fnl)), method, csize, usize, lho });
    p += 46 + fnl + exl + cml;
  }
  return entries;
};
Z.extract = async (buf, e) => {
  const dv = new DataView(buf), p = e.lho;
  const fnl = dv.getUint16(p + 26, true), exl = dv.getUint16(p + 28, true);
  const data = new Uint8Array(buf, p + 30 + fnl + exl, e.csize);
  if (e.method === 0) return data.slice();
  const ds = new DecompressionStream("deflate-raw"); const w = ds.writable.getWriter(); w.write(data); w.close();
  return new Uint8Array(await new Response(ds.readable).arrayBuffer());
};
Z.parseSheet = (xml, strs) => {
  const out = []; let hdr = null;
  for (const rw of xml.matchAll(/<row [^>]*>(.*?)<\/row>/gs)) {
    const obj = {};
    for (const m of rw[1].matchAll(/<c r="([A-Z]+)\d+"(?:[^>]*?t="(\w+)")?[^>]*?(?:\/>|>(.*?)<\/c>)/gs)) {
      const v = ((m[3] || "").match(/<v>(.*?)<\/v>/) || [])[1];
      obj[m[1]] = v === undefined ? "" : (m[2] === "s" ? strs[+v] : v);
    }
    if (!hdr) { if (Object.values(obj).some(v => /MB_CODE_2021/i.test(v))) hdr = obj; continue; }
    if (/^\d{11}$/.test(obj.A)) out.push({ mb: obj.A, cat: obj.B, dw: +obj.D, pp: +obj.E });
  }
  return out;
};
/** @param {string[]} sa1Codes  11-digit SA1 codes. Returns a compact string to paste into partB2. */
async function partA(sa1Codes) {
  // --- PEP P01 (place of enumeration, SA1) ---
  const pepBuf = await (await fetch("https://www.abs.gov.au/census/find-census-data/datapacks/download/2021_PEP_SA1_for_NSW_short-header.zip")).arrayBuffer();
  const pepDir = Z.readZipDir(pepBuf);
  const csv = new TextDecoder().decode(await Z.extract(pepBuf, pepDir.find(e => /P01_NSW_SA1\.csv$/.test(e.name))));
  const lines = csv.split(/\r?\n/).filter(Boolean), hdr = lines[0].split(","), iTot = hdr.indexOf("Tot_P_P");
  const want = new Set(sa1Codes);
  const pep = lines.slice(1).map(l => l.split(",")).filter(c => want.has(c[0])).map(c => "s" + c[0] + "t" + c[iTot]);
  // --- Mesh Block counts (NSW = Table 1 + Table 1.1 = sheet2 + sheet3) ---
  const mbBuf = await (await fetch("https://www.abs.gov.au/census/guide-census-data/mesh-block-counts/2021/Mesh%20Block%20Counts%2C%202021.xlsx")).arrayBuffer();
  const mbDir = Z.readZipDir(mbBuf);
  const ss = new TextDecoder().decode(await Z.extract(mbBuf, mbDir.find(e => e.name === "xl/sharedStrings.xml")));
  const strs = [...ss.matchAll(/<si>(.*?)<\/si>/gs)].map(m => [...m[1].matchAll(/<t[^>]*>(.*?)<\/t>/gs)].map(x => x[1]).join(""));
  const rows = [];
  for (const sh of ["xl/worksheets/sheet2.xml", "xl/worksheets/sheet3.xml"])
    rows.push(...Z.parseSheet(new TextDecoder().decode(await Z.extract(mbBuf, mbDir.find(e => e.name === sh))), strs));
  const nswMB = new Map(rows.map(r => [r.mb, r]));
  // --- which Mesh Blocks belong to those SA1s (ABS ASGS service, CORS-open) ---
  const p = new URLSearchParams({ where: "sa1_code_2021 IN ('" + sa1Codes.join("','") + "')", outFields: "mb_code_2021,sa1_code_2021", returnGeometry: "false", f: "json", resultRecordCount: "2000" });
  const j = await (await fetch("https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/MB/MapServer/0/query?" + p)).json();
  const mb = j.features.map(f => { const a = f.attributes, c = nswMB.get(a.mb_code_2021) || { dw: 0, pp: 0 }; return "m" + a.mb_code_2021 + "s" + a.sa1_code_2021 + "d" + c.dw + "p" + c.pp; });
  const out = "MB " + mb.join(" ") + " PEP " + pep.join(" ");
  console.log(out);
  return out;
}

Step B - Scope it to Forest Lodge

Geometry helpers, the shapefile and ZIP writers, and partB1(), which fetches the suburb polygon, its Mesh Blocks, lots and address points.

// ======================= PART B (portal.spatial.nsw.gov.au tab) =================
const G = {};
G.pip = (pt, ring) => { let inside = false; for (let i = 0, j = ring.length - 1; i < ring.length; j = i++) { const xi = ring[i][0], yi = ring[i][1], xj = ring[j][0], yj = ring[j][1]; if (((yi > pt[1]) !== (yj > pt[1])) && (pt[0] < (xj - xi) * (pt[1] - yi) / (yj - yi) + xi)) inside = !inside; } return inside; };
G.pipPoly = (pt, rings) => { let c = 0; for (const r of rings) if (G.pip(pt, r)) c++; return c % 2 === 1; };
G.centroid = (rings) => { const r = rings[0]; let a = 0, cx = 0, cy = 0; for (let i = 0, j = r.length - 1; i < r.length; j = i++) { const f = r[j][0] * r[i][1] - r[i][0] * r[j][1]; a += f; cx += (r[j][0] + r[i][0]) * f; cy += (r[j][1] + r[i][1]) * f; } a *= 0.5; return a === 0 ? r[0] : [cx / (6 * a), cy / (6 * a)]; };
G.queryAll = async (url, params) => {
  const feats = []; let off = 0;
  while (true) {
    const p = new URLSearchParams({ ...params, f: "json", resultOffset: String(off), resultRecordCount: "2000" });
    const j = await (await fetch(url + "/query", { method: "POST", body: p, headers: { "Content-Type": "application/x-www-form-urlencoded" } })).json();
    if (j.error) throw new Error(JSON.stringify(j.error));
    feats.push(...j.features); if (!j.exceededTransferLimit || !j.features.length) break; off += j.features.length;
  }
  return feats;
};
// ---- shapefile + zip writers (no libraries) ----
G.crcTable = (() => { const t = new Uint32Array(256); for (let n = 0; n < 256; n++) { let c = n; for (let k = 0; k < 8; k++) c = c & 1 ? 0xEDB88320 ^ (c >>> 1) : c >>> 1; t[n] = c >>> 0; } return t; })();
G.crc32 = (u8) => { let c = 0xFFFFFFFF; for (let i = 0; i < u8.length; i++) c = G.crcTable[(c ^ u8[i]) & 0xFF] ^ (c >>> 8); return (c ^ 0xFFFFFFFF) >>> 0; };
G.zipStore = (files) => {
  const enc = new TextEncoder(), parts = [], cd = []; let off = 0; const dd = (2021 - 1980) << 9 | (8 << 5) | 10;
  for (const f of files) {
    const n = enc.encode(f.name), crc = G.crc32(f.data);
    const h = new DataView(new ArrayBuffer(30)); h.setUint32(0, 0x04034b50, true); h.setUint16(4, 20, true); h.setUint16(12, dd, true); h.setUint32(14, crc, true); h.setUint32(18, f.data.length, true); h.setUint32(22, f.data.length, true); h.setUint16(26, n.length, true);
    parts.push(new Uint8Array(h.buffer), n, f.data);
    const c = new DataView(new ArrayBuffer(46)); c.setUint32(0, 0x02014b50, true); c.setUint16(4, 20, true); c.setUint16(6, 20, true); c.setUint16(14, dd, true); c.setUint32(16, crc, true); c.setUint32(20, f.data.length, true); c.setUint32(24, f.data.length, true); c.setUint16(28, n.length, true); c.setUint32(42, off, true);
    cd.push(new Uint8Array(c.buffer), n); off += 30 + n.length + f.data.length;
  }
  const cdLen = cd.reduce((s, p) => s + p.length, 0);
  const e = new DataView(new ArrayBuffer(22)); e.setUint32(0, 0x06054b50, true); e.setUint16(8, files.length, true); e.setUint16(10, files.length, true); e.setUint32(12, cdLen, true); e.setUint32(16, off, true);
  const all = [...parts, ...cd, new Uint8Array(e.buffer)], out = new Uint8Array(all.reduce((s, p) => s + p.length, 0)); let p = 0; all.forEach(a => { out.set(a, p); p += a.length; }); return out;
};
G.writeShp = (polys) => {
  const recs = []; let total = 100; let bx0 = 1e9, by0 = 1e9, bx1 = -1e9, by1 = -1e9;
  polys.forEach((rings, i) => {
    const npts = rings.reduce((s, r) => s + r.length, 0), len = 44 + 4 * rings.length + 16 * npts, b = new DataView(new ArrayBuffer(8 + len));
    b.setInt32(0, i + 1, false); b.setInt32(4, len / 2, false); b.setInt32(8, 5, true);
    let x0 = 1e9, y0 = 1e9, x1 = -1e9, y1 = -1e9; rings.forEach(r => r.forEach(p => { if (p[0] < x0) x0 = p[0]; if (p[0] > x1) x1 = p[0]; if (p[1] < y0) y0 = p[1]; if (p[1] > y1) y1 = p[1]; }));
    b.setFloat64(12, x0, true); b.setFloat64(20, y0, true); b.setFloat64(28, x1, true); b.setFloat64(36, y1, true); b.setInt32(44, rings.length, true); b.setInt32(48, npts, true);
    let o = 52, start = 0; rings.forEach(r => { b.setInt32(o, start, true); o += 4; start += r.length; });
    rings.forEach(r => r.forEach(p => { b.setFloat64(o, p[0], true); b.setFloat64(o + 8, p[1], true); o += 16; }));
    recs.push({ buf: new Uint8Array(b.buffer), off: total, len }); total += 8 + len;
    if (x0 < bx0) bx0 = x0; if (y0 < by0) by0 = y0; if (x1 > bx1) bx1 = x1; if (y1 > by1) by1 = y1;
  });
  const hdr = (fileLen) => { const h = new DataView(new ArrayBuffer(100)); h.setInt32(0, 9994, false); h.setInt32(24, fileLen / 2, false); h.setInt32(28, 1000, true); h.setInt32(32, 5, true); h.setFloat64(36, bx0, true); h.setFloat64(44, by0, true); h.setFloat64(52, bx1, true); h.setFloat64(60, by1, true); return new Uint8Array(h.buffer); };
  const shp = new Uint8Array(total); shp.set(hdr(total), 0); recs.forEach(r => shp.set(r.buf, r.off));
  const shx = new Uint8Array(100 + 8 * recs.length); shx.set(hdr(shx.length), 0); const sv = new DataView(shx.buffer); recs.forEach((r, i) => { sv.setInt32(100 + 8 * i, r.off / 2, false); sv.setInt32(104 + 8 * i, r.len / 2, false); });
  return { shp, shx };
};
G.writeDbf = (fields, rows) => {
  const enc = new TextEncoder(), recLen = 1 + fields.reduce((s, f) => s + f.len, 0), hdrLen = 32 + 32 * fields.length + 1;
  const buf = new Uint8Array(hdrLen + recLen * rows.length + 1), dv = new DataView(buf.buffer);
  buf[0] = 3; buf[1] = 121; buf[2] = 8; buf[3] = 10; dv.setUint32(4, rows.length, true); dv.setUint16(8, hdrLen, true); dv.setUint16(10, recLen, true); buf[29] = 0x57;
  fields.forEach((f, i) => { const o = 32 + 32 * i; buf.set(enc.encode(f.name.slice(0, 10)), o); buf[o + 11] = f.type.charCodeAt(0); buf[o + 16] = f.len; buf[o + 17] = f.dec || 0; });
  buf[hdrLen - 1] = 0x0D; let p = hdrLen;
  rows.forEach(r => { buf[p++] = 0x20; fields.forEach(f => { let s; const v = r[f.name]; if (f.type === "N") s = (v === null || v === undefined || v === "") ? "" : (f.dec ? Number(v).toFixed(f.dec) : String(Math.round(Number(v)))), s = s.padStart(f.len, " "); else s = String(v ?? "").replace(/[^\x20-\x7E]/g, "?").slice(0, f.len).padEnd(f.len, " "); buf.set(enc.encode(s), p); p += f.len; }); });
  buf[p] = 0x1A; return buf;
};

/** Step B1: pick the suburb, get its Mesh Blocks, lots and address points. Prints the SA1 codes for partA. */
async function partB1(suburbName, stateCode = "1") {
  const sal = (await G.queryAll("https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/SAL/MapServer/0", { where: `sal_name_2021='${suburbName.replace("'", "''")}' AND state_code_2021='${stateCode}'`, outFields: "sal_code_2021,sal_name_2021", returnGeometry: "true", outSR: "4326" }))[0];
  if (!sal) throw new Error("suburb not found");
  const rings = sal.geometry.rings, geom = { geometry: JSON.stringify({ rings, spatialReference: { wkid: 4326 } }), geometryType: "esriGeometryPolygon", inSR: "4326", spatialRel: "esriSpatialRelIntersects", outSR: "4326", where: "1=1", returnGeometry: "true" };
  const mbsAll = await G.queryAll("https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/MB/MapServer/0", { ...geom, outFields: "mb_code_2021,mb_category_2021,sa1_code_2021" });
  const mbs = mbsAll.filter(f => G.pipPoly(G.centroid(f.geometry.rings), rings));   // Mesh Blocks whose centroid is in the suburb
  const base = "https://portal.spatial.nsw.gov.au/server/rest/services/";
  const lots = await G.queryAll(base + "NSW_Land_Parcel_Property_Theme/FeatureServer/8", { ...geom, outFields: "cadid,lotidstring,lotnumber,planlabel,classsubtype,planlotarea,planlotareaunits" });
  const addr = await G.queryAll(base + "NSW_Geocoded_Addressing_Theme/FeatureServer/1", { ...geom, outFields: "address" });
  const sa1s = [...new Set(mbs.map(f => f.attributes.sa1_code_2021))];
  console.log("SA1 codes for partA:", JSON.stringify(sa1s));
  return { suburb: sal.attributes.sal_name_2021, mbs, lots, addr, sa1s };
}

/** Step B2: disaggregate, write the zipped shapefile, download it (and optionally push it into the Add Data widget). */

Step C - Transform and disaggregate to lots

partB2(): the two-stage split, SA1 to Mesh Block and Mesh Block to lot, and the write-out of the zipped shapefile.

async function partB2(ctx, absString, { download = true, inject = false } = {}) {
  const mbCounts = new Map([...absString.matchAll(/m(\d{11})s(\d{11})d(\d+)p(\d+)/g)].map(m => [m[1], { sa1: m[2], dw: +m[3], pp: +m[4] }]));
  const pep = new Map([...absString.matchAll(/s(\d{11})t(\d+)/g)].map(m => [m[1], +m[2]]));
  const { mbs, lots, addr } = ctx;
  // lot bbox index + address -> lot
  lots.forEach(l => { let x0 = 1e9, y0 = 1e9, x1 = -1e9, y1 = -1e9; l.geometry.rings.forEach(r => r.forEach(p => { if (p[0] < x0) x0 = p[0]; if (p[0] > x1) x1 = p[0]; if (p[1] < y0) y0 = p[1]; if (p[1] > y1) y1 = p[1]; })); l.bbox = [x0, y0, x1, y1]; l.addrs = []; l.cen = G.centroid(l.geometry.rings); const mb = mbs.find(m => G.pipPoly(l.cen, m.geometry.rings)); l.mb = mb ? mb.attributes.mb_code_2021 : null; });
  addr.forEach(a => { const pt = [a.geometry.x, a.geometry.y]; const l = lots.find(f => pt[0] >= f.bbox[0] && pt[0] <= f.bbox[2] && pt[1] >= f.bbox[1] && pt[1] <= f.bbox[3] && G.pipPoly(pt, f.geometry.rings)); if (l) l.addrs.push(a.attributes.address); });
  lots.forEach(l => { const units = l.addrs.filter(s => /^\S+\//.test(s)); l.nAddr = l.addrs.length; l.nUnit = units.length; l.w = units.length || l.addrs.length; });
  // stage 1: SA1 -> MB
  const mbPersons = new Map();
  for (const [sa1, tot] of pep) { const ms = [...mbCounts].filter(([, v]) => v.sa1 === sa1); let ws = ms.map(([, v]) => v.pp); if (ws.every(w => !w)) ws = ms.map(([, v]) => v.dw); if (ws.every(w => !w)) ws = ms.map(() => 1); const S = ws.reduce((a, b) => a + b, 0); ms.forEach(([k], i) => mbPersons.set(k, tot * ws[i] / S)); }
  // stage 2: MB -> lots
  const byMB = {}; lots.filter(l => l.mb).forEach(l => (byMB[l.mb] = byMB[l.mb] || []).push(l));
  for (const [mb, P] of mbPersons) { const ls = byMB[mb]; if (!ls) continue; let ws = ls.map(l => l.w); if (ws.every(w => !w)) ws = ls.map(l => Math.abs(l.attributes.planlotarea || 1)); const S = ws.reduce((a, b) => a + b, 0); ls.forEach((l, i) => l.persons = P * ws[i] / S); }
  const kept = lots.filter(l => l.mb).sort((a, b) => a.attributes.lotidstring.localeCompare(b.attributes.lotidstring));
  const catOf = new Map(mbs.map(f => [f.attributes.mb_code_2021, f.attributes.mb_category_2021]));
  const rows = kept.map(l => { const a = l.attributes, mc = mbCounts.get(l.mb), P = l.persons || 0; return { LOTID: a.lotidstring, CADID: a.cadid, LOTNUM: a.lotnumber || "", PLANLABEL: a.planlabel || "", CLASSSUB: a.classsubtype, LOTAREA_M2: a.planlotareaunits === "Meters" ? a.planlotarea : (a.planlotareaunits === "Hectares" ? a.planlotarea * 10000 : null), SUBURB: ctx.suburb, MB_CODE21: l.mb, MB_CAT: catOf.get(l.mb), SA1_CODE21: mc.sa1, SA1_ENUM: pep.get(mc.sa1), MB_URP: mc.pp, MB_DWELL: mc.dw, MB_ENUM_E: +mbPersons.get(l.mb).toFixed(2), N_ADDR: l.nAddr, N_UNITS: l.nUnit, WEIGHT: l.w, PERSONS: +P.toFixed(2), PERSONS_R: Math.round(P), METHOD: "SA1 PEP->MB by URP; MB->lot by address pts", CENSUS: "2021-08-10" }; });
  const fields = [{ name: "LOTID", type: "C", len: 30 }, { name: "CADID", type: "N", len: 12 }, { name: "LOTNUM", type: "C", len: 10 }, { name: "PLANLABEL", type: "C", len: 12 }, { name: "CLASSSUB", type: "N", len: 2 }, { name: "LOTAREA_M2", type: "N", len: 12, dec: 1 }, { name: "SUBURB", type: "C", len: 20 }, { name: "MB_CODE21", type: "C", len: 11 }, { name: "MB_CAT", type: "C", len: 20 }, { name: "SA1_CODE21", type: "C", len: 11 }, { name: "SA1_ENUM", type: "N", len: 8 }, { name: "MB_URP", type: "N", len: 8 }, { name: "MB_DWELL", type: "N", len: 8 }, { name: "MB_ENUM_E", type: "N", len: 10, dec: 2 }, { name: "N_ADDR", type: "N", len: 6 }, { name: "N_UNITS", type: "N", len: 6 }, { name: "WEIGHT", type: "N", len: 6 }, { name: "PERSONS", type: "N", len: 10, dec: 2 }, { name: "PERSONS_R", type: "N", len: 8 }, { name: "METHOD", type: "C", len: 50 }, { name: "CENSUS", type: "C", len: 10 }];
  const { shp, shx } = G.writeShp(kept.map(l => l.geometry.rings)), dbf = G.writeDbf(fields, rows);
  const nm = "census2021_night_persons_" + ctx.suburb.toLowerCase().replace(/\W+/g, "_") + "_lots";
  const zip = G.zipStore([{ name: nm + ".shp", data: shp }, { name: nm + ".shx", data: shx }, { name: nm + ".dbf", data: dbf }, { name: nm + ".prj", data: new TextEncoder().encode('GEOGCS["GCS_WGS_1984",DATUM["D_WGS_1984",SPHEROID["WGS_1984",6378137.0,298.257223563]],PRIMEM["Greenwich",0.0],UNIT["Degree",0.0174532925199433]]') }, { name: nm + ".cpg", data: new TextEncoder().encode("UTF-8") }]);
  console.log(`lots ${rows.length}, persons ${rows.reduce((s, r) => s + r.PERSONS, 0).toFixed(1)} of SA1 total ${[...pep.values()].reduce((a, b) => a + b, 0)}, zip ${zip.length} bytes`);
  if (download) { const url = URL.createObjectURL(new Blob([zip], { type: "application/zip" })); const a = document.createElement("a"); a.href = url; a.download = nm + ".zip"; document.body.appendChild(a); a.click(); setTimeout(() => { URL.revokeObjectURL(url); a.remove(); }, 5000); }
  if (inject) { const input = document.querySelector('input[type=file]'); if (input) { const dt = new DataTransfer(); dt.items.add(new File([zip], nm + ".zip", { type: "application/zip" })); input.files = dt.files; input.dispatchEvent(new Event("change", { bubbles: true })); } }
  return { rows, zip, name: nm + ".zip" };
}

Colour coding on the map

Restyles the uploaded layer in the live map: outline-only orange, as shown in the figures, or a graduated fill by PERSONS_R.

// ===================== PART C - colour coding on the map ======================
/*
 * SDT Explorer symbolises an uploaded layer with its own default (a dark purple
 * diagonal hatch), which buries the aerial photo underneath. These helpers
 * restyle the layer in place, in the live map.
 *
 * getView()          - reaches the ArcGIS MapView object the React app owns.
 * styleOutline()     - the look used for the published figures: no fill, bright
 *                      orange lot outlines, so the imagery still reads through.
 * styleByPersons()   - graduated fill by PERSONS_R (pale → deep orange), for
 *                      reading census-night density across the suburb.
 *
 * Both take effect immediately; re-uploading the file resets to the default.
 */
const ORANGE = [255, 120, 0];

/** Find the Esri MapView instance inside the portal's React tree. */
function getView() {
  const el = document.querySelector(".esri-view");
  const key = Object.keys(el).find(k => k.startsWith("__reactFiber"));
  const isView = o => o && typeof o === "object" && o.map && o.map.layers && typeof o.goTo === "function";
  let f = el[key], depth = 0;
  while (f && depth < 60) {
    for (const c of [f.memoizedProps, f.memoizedState, f.stateNode]) {
      if (!c || typeof c !== "object") continue;
      if (isView(c)) return c;
      for (const k of Object.keys(c)) {
        try { const v = c[k]; if (isView(v)) return v; if (v && v.current && isView(v.current)) return v.current; } catch (e) {}
      }
    }
    let h = f.memoizedState, n = 0;
    while (h && n < 30) { const ms = h.memoizedState; if (isView(ms)) return ms; if (ms && ms.current && isView(ms.current)) return ms.current; h = h.next; n++; }
    f = f.return; depth++;
  }
  return null;
}

const censusLayer = (view) => view.map.layers.find(l => l.type === "feature" && /census2021/.test(l.title || ""));

/** Outline-only orange - what Fig. 1 and Fig. 2 in the write-up show. */
function styleOutline(width = 1.5) {
  const view = getView(); const lyr = view && censusLayer(view);
  if (!lyr) return console.warn("census layer not found - upload it first");
  lyr.renderer = { type: "simple", symbol: { type: "simple-fill", style: "none", outline: { color: [...ORANGE, 1], width } } };
  return lyr;
}

/** Graduated orange fill by estimated census-night persons on the lot. */
function styleByPersons(breaks = [0, 1, 4, 21, 101]) {
  const view = getView(); const lyr = view && censusLayer(view);
  if (!lyr) return console.warn("census layer not found - upload it first");
  const alphas = [0.05, 0.14, 0.26, 0.40, 0.60];
  lyr.renderer = {
    type: "class-breaks", field: "PERSONS_R",
    classBreakInfos: breaks.map((min, i) => ({
      minValue: min,
      maxValue: i + 1 < breaks.length ? breaks[i + 1] - 1 : 100000,
      label: i + 1 < breaks.length ? `${min}–${breaks[i + 1] - 1}` : `${min}+`,
      symbol: { type: "simple-fill", color: [...ORANGE, alphas[i]], outline: { color: [...ORANGE, 0.9], width: 0.7 } }
    }))
  };
  return lyr;
}
